# Commit messages

Commit only when asked. When changes warrant a commit and are not yet
committed, end the turn with a message the user can copy.

- Match recent commits — check `git log`. Here the subject is short and
  imperative and the body carries the reasoning and the numbers, in
  paragraphs.
- Skip it for a fix to your own slip, for untracked files, or when committing
  now would leave the repo broken — say what is broken instead.
